# stayingsimpleapps.github.io

Developer site for Staying Simple Apps, served by GitHub Pages at https://stayingsimpleapps.github.io.

- `app-ads.txt`: one file for every app. It lists the AdMob publisher ID and must stay at the site root.
- `<app>/privacy.html`: one privacy policy per app. Copy `amortiq/privacy.html` for a new app and edit what it collects.
- `index.html`: the app list. Add a card per app.

Every store listing uses https://stayingsimpleapps.github.io as the developer website. Don't rename the account or
move these files: store listings, AdMob and the apps link to these exact URLs.
